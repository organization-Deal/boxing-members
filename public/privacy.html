นโยบายความเป็นส่วนตัว
DEAL! Boxing Club

เอกสารร่างสำหรับการพัฒนา: ต้องให้ฝ่ายกฎหมาย/ผู้ควบคุมข้อมูลตรวจทาน และกรอกข้อมูลติดต่อพร้อมรายละเอียดระยะเวลาเก็บรักษาก่อนเปิดรับสมาชิกจริง

1. ข้อมูลที่เก็บ

เมื่อใช้ LINE Login เพื่อสมัครสมาชิก ระบบอาจเก็บ LINE User ID, ชื่อที่แสดงบน LINE, วันที่สมัคร, เวลาที่เข้าใช้ระบบ, ประวัติการเช็กอินและรหัสตู้ รวมถึงตัวเลือกความยินยอมการตลาด เราไม่จำเป็นต้องขออีเมลหรือเบอร์โทรศัพท์ในเวอร์ชันนี้

2. วัตถุประสงค์

  • ยืนยันตัวตนและจัดการบัญชีสมาชิก
  • บันทึกกิจกรรมเช็กอินที่ตู้ซึ่งสมาชิกเลือกบันทึกเอง
  • ส่งข่าวสารการตลาดเฉพาะเมื่อผู้ใช้เลือกยินยอมและช่องทาง LINE รองรับ
  • ดูแลความปลอดภัยและคุณภาพระบบ

3. ข้อจำกัดของข้อมูล

การสแกนหรือเช็กอินไม่ใช่หลักฐานว่าชำระเงินหรือเริ่มเกมแล้ว ระบบสมาชิกนี้ไม่ได้เชื่อมกับระบบรับเงินของ QR BOX, AKI หรือ T-DEV

4. การถอนความยินยอม / การลบ

สมาชิกสามารถเปลี่ยนการยินยอมรับข่าวสาร และส่งคำสั่งลบบัญชีในหน้าโปรไฟล์ได้โดยตรง หากข้อมูลบางรายการจำเป็นต้องเก็บตามกฎหมาย ให้ผู้ควบคุมข้อมูลอธิบายข้อยกเว้นในนโยบายฉบับเผยแพร่จริง

5. ผู้ควบคุมข้อมูลและช่องทางติดต่อ

ต้องกรอกก่อนเปิดจริง: ชื่อนิติบุคคลเต็ม, ที่อยู่, อีเมลติดต่อเรื่องข้อมูลส่วนบุคคล, วันที่เริ่มบังคับใช้ และระยะเวลาเก็บข้อมูลตามนโยบายของบริษัท

6. ความปลอดภัย

ระบบใช้การยืนยันตัวตน LINE ที่ตรวจสอบโทเค็นโดยฝั่ง Server และจำกัดการเข้าถึงข้อมูลสมาชิกด้วย Session ที่ลงลายเซ็น

เวอร์ชันร่าง — ไม่ควรใช้เผยแพร่ก่อนฝ่ายกฎหมายตรวจทาน
